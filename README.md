## GitHub Network Call - GitHub User Search
A lightweight app that fetches GitHub user profiles using the GitHub API.

### Features
- **API Integration** - Search GitHub profiles by username.
- **Error Handling** - Displays appropriate messages for failed searches.
- **Concurrency** - Utilizes `async/await ` for efficient API calls.

### Technology Used
- **Swift** - Core language
- **SwiftUI** - UI framework
- **URLSession** - Network requests
- **Decodable Protocol** - For handling API response (JSON)

### How to Run
1. Clone the repository.
```
git clone https://github.com/DTeakell/GitHub-Network-Call.git
```
2. Open in Xcode.
3. Build and run on an iPhone simulator or physical device.

### Requirements
- **Xcode 15 +**
- **iOS 16 +**
